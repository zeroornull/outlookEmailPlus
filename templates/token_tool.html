🔑 OAuth Token 工具

通过 Microsoft OAuth 获取 Token 并自动导入本次授权的邮箱，无需选择账号。支持个人 Microsoft 账号（tenant=consumers、IMAP / Graph），可使用服务器配置的 Web 应用凭据或公共客户端。

📘 Azure 应用注册快速指引

如果你是第一次使用，请先在 Azure 门户注册一个应用，获取 Client ID 后再填写下方配置。

①
注册应用

进入 Azure 门户 → 应用注册，点击「新注册」。

  • 名称：自定义（如 "OutlookEmailPlus"）
  • 受支持的账户类型：选择「Accounts in any organizational directory and personal Microsoft accounts」（任意目录 + 个人账号）
  • 工具仅支持个人 Microsoft 账号，授权使用 tenant=consumers。
②
选择客户端模式

Web 应用：在「证书和密码」创建客户端密码，将密码值与应用 ID 配对配置为服务器的 OAUTH_CLIENT_SECRET / OAUTH_CLIENT_ID。

公共客户端可不配置 secret；仅此模式按 Azure 要求开启「允许公共客户端流」。Web 应用无需开启此选项，secret 不会发送到浏览器。

③
配置 API 权限

进入应用 →「API 权限」→「添加权限」→ 选择「Microsoft Graph」→「委托的权限」，添加以下权限：

  • offline_access（必须，用于获取 refresh_token）
  • openid profile email（识别本次授权的邮箱，用于自动导入）
  • Mail.Read（读取邮件）
  • User.Read（读取用户信息）

💡 推荐使用 Graph 协议（本系统默认邮件读取主链路），直接使用「Graph 邮件」预设即可。

④
配置重定向 URI

在「身份验证」页面选择与客户端模式对应的平台，并将同一地址填入下方 Redirect URI。

  • Web：使用「Web」平台，远程部署填写本服务的 HTTPS 回调地址，如 https://example.com/token-tool/callback；本地可使用实际 localhost 回调地址。
  • 公共客户端：使用「Mobile and desktop applications」平台的 public redirect，如 http://localhost，授权后手动复制地址栏 URL 粘贴回本工具。
⑤
获取 Client ID

回到应用「概述」页面，复制「应用程序(客户端) ID」，粘贴到下方 OAuth 配置的 Client ID 输入框中。
